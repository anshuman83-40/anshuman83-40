## ⭐ Featured project: Churn & Retention Optimizer

**[Live demo](https://churn-retention-optimizer.onrender.com)** · **[Code](https://github.com/anshuman83-40/churn-retention-optimizer)** · **[How the model works](https://github.com/anshuman83-40/churn-retention-optimizer/blob/main/docs/OWN_MODEL.md)**

[![ChurnOpt dashboard](https://raw.githubusercontent.com/anshuman83-40/churn-retention-optimizer/main/docs/dashboard-dark.png)](https://churn-retention-optimizer.onrender.com)

Predicts which telecom customers will leave, explains why, and decides **who is actually worth a discount**
using causal uplift modelling.

- **ChurnUpliftNet**, my own model written from scratch in NumPy: one network predicts churn risk and the
  offer's effect. It matches XGBoost on churn (ROC-AUC 0.846 vs 0.847), verified by a gradient-check test
- Uplift targeting earns **2.4x the value** of risk-based targeting at the same budget (simulated experiment)
- FastAPI backend, custom light/dark dashboard, Docker, GitHub Actions CI, 24 tests
